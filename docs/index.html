Dlaczego MiStick Lite?

Minimalizm

Jeden rząd aplikacji, zegar i trzy pozycje menu. Bez rekomendacji i reklam w launcherze.

Obsługa pilotem

Nawigacja przyciskami kierunkowymi, OK i Wstecz. Zmiana kolejności oraz ukrywanie aplikacji.

Małe wymagania

Natywny Kotlin i Android Views, bez Compose oraz rozbudowanych bibliotek interfejsu.

Automatyczne wykrywanie

Nowo zainstalowane aplikacje pojawiają się w rzędzie bez ręcznego dodawania.

Instalacja

Projekt testowano na Xiaomi Mi TV Stick Full HD, model MiTV-AESP0, Android TV 9, firmware PI.2055. Wymagane jest ADB.

adb connect ADRES_IP_STICKA:5555
adb install -r MiStickLite.apk
adb shell am start -n pl.misticklite/.MainActivity

Zastąp nazwę APK rzeczywistą nazwą pobranego pliku. Samo zainstalowanie aplikacji nie ustawia jej jako domyślnego ekranu Home.

Konfiguracja i bezpieczeństwo

Wyłączanie systemowego launchera lub komponentów konfiguracji Android TV jest operacją zaawansowaną. Może wpłynąć na działanie urządzenia i możliwość przywrócenia ustawień. Nie wykonuj takich zmian bez sprawnego połączenia ADB i przygotowanej procedury przywracania oryginalnego launchera.

Szczegółowa dokumentacja i procedury diagnostyczne znajdują się w README projektu.
